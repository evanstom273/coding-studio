# Godot editor plugin

`apps/godot-addon/addons/coding_studio` adds a **Visual Script** main screen to Godot 4.2+ that edits the same `.vproj.json` documents as the web editor and generates ordinary `.gd` files next to them.

## How it works

The plugin is a thin GraphEdit front-end. It does not reimplement the compiler: it talks to the **companion service**, a small local Node process that exposes the shared TypeScript compiler and edit operations over HTTP on `127.0.0.1:47832`:

```
Godot (plugin) ──HTTP 127.0.0.1:47832──► companion (mcp/companion) ──► compiler-core + language-gdscript + project-format (applyOps)
```

So a graph edited in Godot validates, compiles and generates byte-for-byte the same code as in the browser (tested in `tests/integration/companion.test.ts`). The companion is stateless, never touches files, binds to loopback and rejects requests coming from web pages (any `Origin` header). No online service is involved.

## Install

1. Build and start the companion (keep it running while you edit visual scripts):
   ```bash
   npm install
   npm run build:companion
   npm run companion          # Coding Studio companion listening on http://127.0.0.1:47832
   ```
   Port override: `CODING_STUDIO_COMPANION_PORT` (and change `base_url` in `companion_client.gd`).
2. Copy `apps/godot-addon/addons/coding_studio` into your project's `addons/` folder.
3. *Project → Project Settings → Plugins* → enable **Coding Studio Visual Scripts**.
4. Click **Visual Script** in the top bar.

Or open `apps/godot-addon` itself in Godot: it is a demo project with the plugin enabled and all 12 examples (`examples/<name>/<name>.vproj.json` plus the generated `.gd`).

## Use

| Button | Action |
| --- | --- |
| New | New project document (then choose where to save it) |
| Open… | Open a `.vproj.json` from `res://` |
| Save | Save the document |
| Script / function selectors | Switch graphs |
| Add Node (or right-click the graph) | Searchable node list |
| Generate .gd | Compile and write the scripts next to the `.vproj.json`; scripts already loaded in the editor are reloaded. Existing files without the "Generated by Coding Studio" header are only overwritten after confirmation. |
| Attach to Selected Node | Set the generated script on the selected scene nodes (undoable) |
| Refresh | Reload the document from disk and regenerate (after editing it in the browser) |

Graph editing: drag between ports to connect (types are checked by the companion; rejected connections show the reason in the status line), drag a connected input away to disconnect, Delete removes nodes, moving nodes is saved, unconnected bool/int/float/string inputs have inline fields. The diagnostics list below the graph selects and centres the offending node.

Round-tripping with the browser: export `.vproj.json` from the web editor into your Godot project (or open the plugin's file in the web editor via *Import project*). Both edit the same format.

## Status

The plugin's GDScript has been written against the Godot 4.2+ editor API but **has not been executed in Godot** in the environment it was built in (no Godot binary was available). The companion service it depends on is covered by automated tests. Please report anything that fails to load; see [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).
